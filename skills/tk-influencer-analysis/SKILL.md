# TK Influencer Analysis

这个 skill 用来回答一个核心问题：**某个 TikTok 产品应该找什么达人卖，或者某个达人适不适合卖这个产品？**

它不是只看粉丝数，而是把商品证据、达人证据、视频证据、店铺证据和成交渠道证据放在一起，判断“产品 x 达人”的真实匹配度。

## 核心问题

先判断用户要解决哪一种问题：

- 产品优先：已经有产品或品类，要找适合的达人和视频角度。
- 达人优先：已经有达人，要判断他/她适合卖什么产品。
- 匹配优先：已经有产品和达人，要判断能不能合作。
- 诊断优先：产品、达人或视频表现异常，要找原因。

如果用户只给了一个商品或达人线索，先用 configured data source 快速查一轮，不要直接追问一堆细节。

## 数据规则

运行前读取 `references/data-source.md` 和 `references/data-capabilities.md`，发现当前可用工具并映射逻辑能力。没有兼容数据源时请求配置 MCP 或导入离线文件。

不要只用粉丝数判断达人质量。没有单独广告账户工具时，不要输出广告花费、CPC、CPM、CTR、ROAS、广告系列或广告组数据。

不要把粉丝数、播放量或评论数直接当作成交数据。

## 适用场景

- 用户给一个 TikTok 商品，想找达人。
- 用户给一个达人账号，想判断适合卖什么。
- 用户想判断某个达人是否适合某个产品。
- 用户想分析某个商品为什么达人带货强或弱。
- 用户想对达人名单排序，决定先联系谁。
- 用户想把达人分析转成视频角度或合作 brief。

## 分析流程

1. 识别对象。
   - 商品线索：先用 `tiktok.product_search`，再用 `tiktok.product_detail`。
   - 达人线索：先用 `tiktok.creator_search`，再用 `tiktok.creator_detail`。
   - 店铺线索：先用 `tiktok.shop_search`，再用 `tiktok.shop_detail`。
   - 视频线索：先用 `tiktok.video_search`，再用 `tiktok.video_detail`。

2. 建立商品卡。
   - 用 `tiktok.product_detail` 看标题、类目、价格、评分、店铺、达人数、视频数、销量、销售额。
   - 用 `tiktok.sales_history` 看动量。
   - 用 `tiktok.channel_mix` 看商品卡、店铺自营、达人带货的成交占比。
   - 有条件时用 `tiktok.review_or_voice` 提取用户语言、反对意见和卖点。

3. 建立达人卡。
   - 用 `tiktok.creator_detail` 看粉丝、互动、销量、GPM、简介和脱敏联系方式。
   - 用 `tiktok.creator_detail` 看达人趋势。
   - 有条件时用 `tiktok.creator_detail` 看受众画像。
   - 用 `tiktok.creator_sales` 能力看销售渠道 GMV 占比和商品类目 GMV 占比。

4. 分析视频证据。
   - 用 `tiktok.video_search` 找商品、达人、类目相关视频。
   - 用 `tiktok.video_detail` 看播放和互动。
   - 有条件时用 `tiktok.video_detail`、`tiktok.video_transcript`、`tiktok.video_search`、`tiktok.video_transcript` 看口播、评论和内容结构。

5. 做匹配判断。
   - 产品优先：按类目适配、销售证据、GPM、互动质量、受众匹配、视频形式给达人排序。
   - 达人优先：按达人已有强类目、成交渠道、受众适配、内容可拍性给产品机会排序。
   - 匹配优先：给具体“产品 x 达人”打分，并说明要用什么内容角度才能提高成功率。

## 评分规则

可以使用 100 分制，但必须解释分数背后的机制。

商品可达人化评分：

- 需求和动量：25
- 价格和利润空间：15
- 成交渠道适配：15
- 视频可演示性：15
- 评论/口碑情绪：10
- 竞争和饱和风险：10
- 运营风险：10

达人匹配评分：

- 类目销售证据：25
- 受众适配：20
- 互动和趋势稳定性：15
- GPM 或销售效率：15
- 内容形式适配：15
- 风险：10

某项缺数据时标为“未知”，降低置信度，不要硬凑分。

## 输出格式

默认用中文输出：

```text
结论
- 最佳决策
- 商品可达人化分数
- 达人 / 匹配分数
- 置信度

产品分析
- 需求和动量
- 价格和渠道
- 用户声音
- 风险

达人分析
- 受众 / 类目适配
- 销售证据
- 内容风格
- 风险

视频打法
- 已验证的视频模式
- 推荐内容角度
- 3 个测试脚本或达人 brief

达人名单或匹配判断
- 排名
- 达人
- 为什么匹配
- 证据
- 推荐合作角度

下一步
- 7 天内测试什么
- 下一轮需要补什么数据
```

## 实战规则

- 优先选有相关类目销售证据的达人，不要只选粉丝多的达人。
- 区分“好达人”和“适合这个产品的达人”。
- 如果达人带货弱但商品卡/店铺自营强，先优化内容和商品页，再扩大达人合作。
- 如果视频有播放但没销量，优先诊断内容承诺、用户需求和商品卖点是否错位。
- 如果有销量但评论/口碑暴露反对意见，先围绕反对意见写脚本，再扩大投放或达人合作。
