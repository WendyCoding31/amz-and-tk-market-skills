# Product Chart Get 使用说明

## 输入

先由 Agent 调用当前已配置的 Amazon 数据源，将完整响应保存为 JSON。也可以使用用户提供的离线 JSON。

```bash
python3 scripts/fetch_raw_data.py \
  --input provider-output.json \
  --date 20260407 \
  --limit 20 \
  --provider "configured-source"
```

## 输出

| 文件 | 用途 |
| --- | --- |
| `data-get-第x页数据.json` | 标准化后的完整商品数据；文件名为历史兼容 |
| `mini_products-第x页.json` | AI 语义复筛输入 |
| `meta-第x页.json` | provider、原始文件、日期和数量 |
| `ai_results.json` | AI 输出的中文标题、复筛与季节性判断 |

生成 Excel：

```bash
python3 scripts/generate_excel.py --date 20260407
```

运行时字段映射见 [data-source.md](./data-source.md)。不要把 API Key、Token、Cookie 或 MCP 配置放在这个目录。
