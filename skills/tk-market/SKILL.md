# TK Market

这个 skill 用来回答一个核心问题：**某个 TikTok Shop 产品或品类，值不值得做？**

它不是泛泛做市场调研，而是用真实的商品、品类、店铺、达人、视频和成交渠道数据，输出可以直接用于决策的市场判断。

## 数据规则

运行前读取 `references/data-source.md` 和 `references/data-capabilities.md`。检查当前 Agent 已配置的 MCP/连接器，并把供应商字段映射为逻辑能力；没有兼容数据源时请求用户配置 MCP 或提供 CSV/XLSX/JSON。

外部资料与平台数据必须分开标注。不要编销量、GMV、趋势或达人表现。

## 适用场景

- 用户问某个 TikTok 产品能不能做。
- 用户给一个关键词、品类或商品链接，想判断市场空间。
- 用户想比较多个 TikTok 细分赛道。
- 用户想知道某个品类的价格带、竞争格局、达人供给。
- 用户想判断一个产品更适合商品卡、店铺自营还是达人带货。
- 用户需要一个“进入 / 小规模测试 / 观望 / 放弃”的明确结论。

## 输入信息

优先收集最少信息，先跑第一轮数据：

- 决策目标：进入、放弃、比较、定价、上新、监控。
- 产品或品类线索：关键词、商品名、`commodityId`、类目、店铺、竞品。
- 市场：国家或地区；用户不说时默认美国。
- 时间窗口：默认近 30 天，除非用户指定其他周期。
- 限制条件：目标价格带、履约限制、达人打法、品牌定位等。

如果用户只给了模糊产品想法或 TikTok 链接，先推断关键词并做快速扫描，不要一开始就追问太多。

## 分析流程

1. 明确决策边界。
   - 说明这次到底要回答什么决策。
   - 定义关键词、类目、市场和时间窗口。
   - 说明什么情况算值得做，什么情况算观望或放弃。

2. 衡量品类需求。
   - 用 `tiktok.market_overview` 看国家/类目的销量、销售额、动销商品数和趋势。
   - 用 `tiktok.market_overview` 找一级、二级类目的热度和集中度。
   - 用 `tiktok.market_overview` 判断活跃价格带。

3. 拆竞争格局。
   - 用 `tiktok.product_search` 找关键词或类目下的头部商品。
   - 用 `tiktok.product_detail` 看重点商品详情。
   - 用 `tiktok.sales_history` 看商品动量和波动。
   - 用 `tiktok.channel_mix` 区分商品卡、店铺自营、达人带货的成交占比。

4. 看达人和视频通道。
   - 用 `tiktok.creator_search` 看达人矩阵和粉丝层级。
   - 用 `tiktok.creator_search`、`tiktok.creator_detail` 找相关达人。
   - 用 `tiktok.video_search`、`tiktok.video_detail` 看有效视频形式和带货表现。

5. 看店铺结构。
   - 当店铺是竞争核心时，用 `tiktok.shop_search`、`tiktok.shop_detail`、`tiktok.market_overview`、`tiktok.shop_sales_history` 分析店铺。

6. 给出决策。
   - 从需求、竞争、价格空间、达人可行性、运营风险几个维度打判断。
   - 必须给明确结论：进入、小规模测试、观望、放弃。
   - 说明哪些数据会改变当前判断。

## 证据标准

每个关键判断都要说明来自哪个 configured data source 工具。工具返回空数据、权限限制、详情次数不足或 `data: null` 时，要如实说明，不要用猜测补数字。

置信度分三档：

- 高：多个 configured data source 工具互相印证，且商品、品类、视频或达人证据都比较完整。
- 中：主要信号足够，但缺少一层关键证据。
- 低：只有单层数据，或数据明显稀疏。

## 输出格式

默认用中文输出，结构如下：

```text
结论
- 决策：进入 / 小规模测试 / 观望 / 放弃
- 置信度：高 / 中 / 低
- 一句话理由

市场需求
- 品类或关键词需求
- 销量 / 销售额方向
- 活跃价格带

竞争格局
- 头部商品 / 店铺
- 集中度和饱和度
- 可切入空位

达人与视频通道
- 达人供给
- 成交渠道占比
- 有效内容形式

进入打法
- 推荐切入细分
- 推荐价格带
- 达人 / 视频策略
- 7 天小测试方案

风险
- 数据缺口
- 产品风险
- 运营风险

证据表
- 工具
- 查询条件
- 关键字段
- 支持了哪个判断
```

## 边界

- 不要把 TikTok Shop 商品/视频/达人数据说成 TikTok Ads 广告账户数据。
- 没有单独广告账户工具时，不要输出广告花费、CPC、CPM、CTR、ROAS、广告系列、广告组、预算或出价。
- 不保证爆款、销量或市场成功。
- 热门话题不等于商品需求，必须有商品、销售或达人证据支撑。
